# Cyber Snake Royale — download para testar

Esta branch contém o ZIP da versão corrigida. A branch principal do perfil permanece separada.

Abra `Cyber_Snake_Royale_FINAL.zip` e use **Download raw file** no GitHub. Extraia tudo no Windows e execute `iniciar_windows.bat`. Requer Python 3.10+ instalado, com Add Python to PATH.

O ZIP inclui o guia de uso e o relatório de testes. Foram executados testes de regras, integração, navegador mobile emulado e 30 clientes simultâneos. Windows real, celulares físicos e hospedagem pública ainda precisam de validação.
