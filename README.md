# Cyber Snake Royale — download para testar

Esta branch contém o ZIP da versão corrigida, com arena ampliada para **3.600 × 2.400** (aproximadamente 2,8 vezes a área original). A branch principal do perfil permanece separada.

Abra `Cyber_Snake_Royale_FINAL.zip` e use **Download raw file** no GitHub. Extraia tudo no Windows e execute `iniciar_windows.bat`. Requer Python 3.10+ instalado, com Add Python to PATH.

O ZIP inclui o guia de uso e o relatório de testes. Foram executados testes de regras, integração, navegador mobile emulado e 30 clientes simultâneos. O usuário confirmou a inicialização no Windows. Celulares físicos em turma e hospedagem pública ainda precisam de validação.

## Personalização e poderes

Cinco skins na tela de nome e cor (Neon, Conexões, Listras, Pixel e Galáxia), líder com coroa e bônus de eliminação, ímã/escudo/turbo temporários e homenagem simples à Rede Cidadã. Testes: 25 regras, protocolo, integração, navegador mobile emulado e 30 clientes sincronizados em uma rodada completa. O guia e as evidências estão no ZIP.
